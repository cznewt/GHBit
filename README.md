# GHBit

Extension for Yahboom GHBit_V1/V2 3.0.5

## License

MIT

## Supported targets

* for PXT/microbit

### Yahboom joystick

[Yahboom joystick](https://makecode-microbit.geekedu.eu/#example:/projects/yahboom-joystick): reads the GHBit rocker and sends drive commands over radio.

### Wukong board

Navigate to makecode editor. Install `wukong` extension.

[elecfreak wukong mecanum car](https://makecode-microbit.geekedu.eu/#example:/projects/elecfreak-wukong-mecanum-car)
